# 汉字卡片 — HSK 1급 한자 플래시카드

`index.html` 파일 하나로 동작하는 한자 학습용 플래시카드 웹페이지입니다.

## 사용 방법

1. `index.html` 파일을 더블 클릭하거나 브라우저로 열면 바로 실행됩니다.
2. 별도 설치나 인터넷 연결 없이 오프라인에서도 사용할 수 있습니다.

## 기능

- **카드 뒤집기**: 카드를 클릭하거나 "뒤집기" 버튼을 누르면 앞면(한자) ↔ 뒷면(병음 + 한국어 뜻)이 전환됩니다.
- **이전 / 다음**: 버튼 또는 키보드 ← / → 방향키로 카드를 넘길 수 있습니다.
- **키보드 단축키**
  - `Space`: 카드 뒤집기
  - `←`: 이전 카드
  - `→`: 다음 카드
- **순서 섞기**: "🔀 섞기" 버튼을 누르면 카드 순서가 무작위로 바뀝니다.
- **어려운 카드 표시**: "☆ 어려워요" 버튼으로 지금 보는 카드를 표시(★)해둘 수 있습니다.
- **어려운 카드만 보기**: "⭐ 어려운 카드만" 버튼을 누르면 표시해둔 카드만 모아서 복습할 수 있습니다. 다시 누르면 전체 카드로 돌아옵니다.
- 현재 몇 번째 카드인지 화면 하단에 표시됩니다.

## 디자인

- 배경은 연한 회색, 카드는 흰 배경에 둥근 모서리와 옅은 그림자
- 한자는 크게, 병음은 작게 표시
- 한자는 세리프 계열 폰트(Noto Serif SC 등)로 표시되어 자연스럽게 보입니다
- 버튼은 차분한 무채색 톤이며, 마우스를 올리면 색이 살짝 진해집니다
- 모바일 세로 화면에도 최적화되어 있습니다

## 단어 추가/수정 방법

`index.html` 안의 `<script>` 태그에서 `words` 배열을 찾아 다음과 같은 형식으로 항목을 추가하거나 수정하면 됩니다.

```js
{ hanzi: "汉字", pinyin: "pīnyīn", meaning: "한국어 뜻" },
```
